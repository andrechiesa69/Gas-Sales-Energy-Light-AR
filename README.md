# Gas Sales Energia – AR versione leggera

Tutti i file vanno caricati nella RADICE del repository GitHub (nessuna cartella).
1. Repository pubblico → Add file → Upload files → trascina tutti i file → Commit changes.
2. Settings → Pages → Deploy from a branch → main / (root) → Save.
3. Indirizzo: https://TUO-UTENTE.github.io/NOME-REPO/ (usalo per il QR code).
4. Prova da PC: aggiungi ?preview all'indirizzo.

Contenuti: foto AR del Palazzo Gotico + cerchio (palazzogoticoar.png) e 7 loghi cliccabili.
Posizioni e link: blocco CONFIGURAZIONE in index.html.
